## 🌟 Overview

WalletWise is a modern Android expense tracker designed to help users manage personal finances with ease. The application combines a clean Material 3 interface with powerful features such as recurring transactions, budget tracking, savings goals, analytics, and real-time cloud synchronization through Firebase.

Built using modern Android development practices, WalletWise leverages Jetpack Compose, MVVM Architecture, Kotlin Coroutines, Firestore, and Firebase Authentication to deliver a seamless user experience.

---

## 🚀 Features

### 💸 Expense Management
- Add income and expense transactions
- Edit transactions
- Delete transactions
- Real-time Firestore synchronization
- Instant transaction search
- Categorized expense tracking

### 🔄 Recurring Transactions
- Daily recurring transactions
- Weekly recurring transactions
- Monthly recurring transactions
- Pause recurring transactions
- Resume recurring transactions
- Dedicated recurring transaction management screen

### 💰 Budget Tracking
- Set monthly spending limits
- Monitor remaining budget
- Overspending alerts
- Budget utilization tracking
- Real-time budget updates

### 🎯 Savings Goals
- Create savings goals
- Track goal progress
- Update contributions
- Delete goals

### 📊 Analytics Dashboard
- Income vs Expense overview
- Monthly financial summaries
- Spending insights
- Visual analytics components

### 📅 Calendar View
- Browse transactions by date
- Review spending history
- Quickly access past transactions

### 🔐 Authentication
- Firebase Authentication
- User Registration
- Secure Login
- Secure Logout
- User-specific cloud data
